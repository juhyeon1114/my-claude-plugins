# 배경

- `${CLAUDE_SKILL_DIR}/../syntax/criteria.md`(이하 판단 기준)에 수도코드로 바꾸는 것, 자연어로 두는 것, 효과 등급, 모호한 표현이 정리되어 있다.
- 이 스킬은 후보를 찾기만 한다. 수도코드로 바꾸는 일은 `convert` 스킬이 한다.
- 후보가 없으면 없다고 답한다. 억지로 만들지 않는다.

# 스킬의 동작 방식

## 1단계: 대상 정하기

1. 사용자가 지정한 파일, 문서, 글을 대상으로 삼는다.
2. 폴더를 지정했으면 그 안의 지침 파일을 대상으로 삼는다. `CLAUDE.md`, `SKILL.md`, 에이전트 정의, 출력 스타일이 여기에 든다.
3. 지정하지 않았으면 이 세션에서 사용자가 준 지침과 요청을 대상으로 삼는다.
4. 이미 수도코드로 쓰인 부분과 파일 맨 위의 프론트매터는 대상에서 뺀다.

## 2단계: 후보 찾기

1. 판단 기준을 읽는다.
2. 대상에서 판단 기준의 `수도코드로 바꾸는 것`에 해당하는 구절을 찾는다.
3. 같은 결과 하나를 내려고 이어서 하는 일들은 문장이 떨어져 있어도 후보 하나로 묶는다. 묶을지 나눌지 판단이 서지 않으면 묶는다.
4. 후보마다 효과 등급을 매기고, 낮음은 버린다.
5. 남은 후보에서 판단 기준의 `모호한 표현`에 해당하는 말을 찾는다.

## 3단계: 표로 정리하기

효과가 높은 순서로 아래 표에 정리한다.

| 번호 | 위치 | 원문 요약 | 종류 | 효과 | 모호한 표현 |
|------|------|-----------|------|------|-------------|

- 위치: 파일이면 프로젝트 폴더 기준 경로로 `경로:시작 줄-끝 줄`을 쓴다. 떨어진 줄은 쉼표로 잇는다. 세션이면 사용자의 말을 한 줄로 인용한다.
  - 예) `skills/git/skills/commit/SKILL.md:6-10`, `CLAUDE.md:12, 30-34`
- 원문 요약: 한 문장으로 쓴다.
- 종류: 판단 기준의 종류 이름을 쓴다. 여러 개면 쉼표로 잇는다.
- 효과: `높음`, `중간` 가운데 하나를 쓴다.
- 모호한 표현: 바꾸기 전에 정해야 하는 말을 원문 그대로 인용한다. 없으면 비운다.

표 아래에서 어느 번호를 수도코드로 바꿀지 묻는다. 사용자가 번호를 고르면 `convert` 스킬로 그 후보를 바꾼다.
