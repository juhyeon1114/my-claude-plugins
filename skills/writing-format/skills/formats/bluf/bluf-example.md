# BLUF 예시

제목: [승인 요청] 주문 수집 병렬 처리를 9월 28일에 운영에 적용하려 합니다

팀장님, 주문 수집을 쇼핑몰 4곳씩 동시에 호출하도록 바꾸는 작업을 9월 28일 월요일 오후 2시에 운영에 적용하려 합니다. 9월 25일 금요일까지 승인해 주시면 일정대로 진행하겠습니다.

적용하려는 이유는 두 가지입니다.

- 지금은 한 번 수집하는 데 12분이 걸려서, 10분 주기보다 깁니다. 이 때문에 주문이 늦게 보인다는 고객사 문의가 지난주에만 5건 들어왔습니다.
- 검증 서버에서 실험해 보니 수집 시간이 3분 20초로 줄었고, 쇼핑몰이 호출을 거절한 일은 없었습니다.

문제가 생기면 설정값 하나만 바꿔서 5분 안에 예전 방식으로 되돌릴 수 있습니다.

실험 조건과 측정값은 첨부한 실험 보고서에 정리했습니다.
