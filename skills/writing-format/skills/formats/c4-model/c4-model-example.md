# C4 모델 예시

범례: `[ ]`는 상자다. 상자 뒤에 종류, 기술, 하는 일을 쓴다. `---->`는 호출하는 방향이다.

## 1단계 시스템 맥락: 주문 수집 시스템

```text
[고객사 담당자] 사람: 자기 회사 주문이 제때 들어오는지 확인한다
[주문 수집 시스템] 소프트웨어 시스템: 쇼핑몰에서 새 주문을 모아 창고로 넘긴다
[쇼핑몰 40곳] 외부 시스템: 고객사의 주문을 받는다
[창고 시스템] 외부 시스템: 주문을 받아 출고한다

[고객사 담당자] ---- 수집 현황을 본다 ----> [주문 수집 시스템]
[주문 수집 시스템] ---- 새 주문을 조회한다 ----> [쇼핑몰 40곳]
[주문 수집 시스템] ---- 출고할 주문을 넘긴다 ----> [창고 시스템]
```

## 2단계 컨테이너: 주문 수집 시스템

```text
주문 수집 시스템 경계 안
  [관리 화면] 컨테이너, React: 수집 현황과 실패한 쇼핑몰을 보여 준다
  [수집 서버] 컨테이너, Spring Boot: 10분마다 새 주문을 모아 저장하고 넘긴다
  [주문 데이터베이스] 컨테이너, MySQL: 수집한 주문과 수집 기록을 저장한다

주문 수집 시스템 경계 밖
  [고객사 담당자] 사람: 자기 회사 주문이 제때 들어오는지 확인한다
  [쇼핑몰 40곳] 외부 시스템: 고객사의 주문을 받는다
  [창고 시스템] 외부 시스템: 주문을 받아 출고한다

[고객사 담당자] ---- 수집 현황을 본다 ----> [관리 화면]
[관리 화면] ---- 수집 현황을 요청한다 (HTTPS, JSON) ----> [수집 서버]
[수집 서버] ---- 주문을 읽고 쓴다 (JDBC) ----> [주문 데이터베이스]
[수집 서버] ---- 새 주문을 조회한다 (HTTPS) ----> [쇼핑몰 40곳]
[수집 서버] ---- 출고할 주문을 넘긴다 (HTTPS) ----> [창고 시스템]
```

## 3단계 컴포넌트: 수집 서버

```text
수집 서버 경계 안
  [수집 스케줄러] 컴포넌트, Spring @Scheduled: 10분마다 수집을 시작한다
  [작업 대기열] 컴포넌트, 메모리 대기열: 이번 주기에 수집할 쇼핑몰을 담는다
  [일꾼] 컴포넌트, 스레드 4개: 대기열에서 쇼핑몰을 꺼내 수집한다
  [쇼핑몰 연동 모듈] 컴포넌트, HTTP 클라이언트: 쇼핑몰마다 다른 API 호출 방식을 맞춘다
  [주문 저장소] 컴포넌트, JPA: 수집한 주문을 저장한다

수집 서버 경계 밖
  [쇼핑몰 40곳] 외부 시스템: 고객사의 주문을 받는다
  [주문 데이터베이스] 컨테이너, MySQL: 수집한 주문과 수집 기록을 저장한다

[수집 스케줄러] ---- 10분마다 쇼핑몰 40곳을 넣는다 ----> [작업 대기열]
[일꾼] ---- 쇼핑몰을 하나씩 꺼낸다 ----> [작업 대기열]
[일꾼] ---- 새 주문 조회를 맡긴다 ----> [쇼핑몰 연동 모듈]
[쇼핑몰 연동 모듈] ---- 새 주문을 조회한다 (HTTPS) ----> [쇼핑몰 40곳]
[일꾼] ---- 조회한 주문을 저장한다 ----> [주문 저장소]
[주문 저장소] ---- 주문을 쓴다 (JDBC) ----> [주문 데이터베이스]
```
