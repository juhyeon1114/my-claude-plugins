# CER 예시

질문: 주문 수집이 왜 12분이나 걸릴까?

주장
주문 수집이 오래 걸리는 까닭은 우리 서버가 느려서가 아니라, 쇼핑몰의 응답을 하나씩 차례로 기다리기 때문이다.

증거
- 수집 한 번에 걸린 12분 가운데 11분 30초가 쇼핑몰 응답을 기다린 시간이었다.
- 같은 시간 동안 서버 처리 능력은 5%만 쓰였다.
- 쇼핑몰이 30곳이던 석 달 전에는 9분, 40곳인 지금은 12분이 걸린다. 쇼핑몰 수에 거의 정확히 비례한다.
- 수집 코드는 한 쇼핑몰의 응답을 다 받은 뒤에야 다음 쇼핑몰을 호출한다.

추론
서버가 원인이라면 처리 능력을 많이 쓰고 있어야 하는데, 실제로는 거의 놀고 있었다.
반면 기다린 시간이 전체의 대부분을 차지하고, 쇼핑몰 수에 비례해서 늘었다.
차례로 호출하면 전체 시간은 쇼핑몰마다 기다린 시간을 모두 더한 값이 된다. 그래서 쇼핑몰이 늘수록 기다리는 시간이 그대로 쌓인다.
