# SCQA 예시

## 뼈대

상황
우리 서비스는 여러 쇼핑몰의 주문을 10분마다 모아 온다. 고객사는 주문이 들어온 뒤 10분 안에 우리 화면에서 볼 수 있다고 알고 있다.

문제
그런데 연동 쇼핑몰이 40곳으로 늘면서, 한 번 모으는 데 12분이 걸리게 됐다. 지난주에는 주문이 늦게 보인다는 문의가 5건 들어왔다.

질문
쇼핑몰이 계속 늘어나도 10분 약속을 지키려면 어떻게 해야 할까?

답
쇼핑몰을 하나씩 차례로 호출하지 말고, 4곳씩 동시에 호출해야 한다. 검증 서버에서 실험해 보니 수집 시간이 3분 20초로 줄었다.
