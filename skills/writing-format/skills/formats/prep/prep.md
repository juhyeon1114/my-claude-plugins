# PREP

주장 (Point), 이유 (Reason), 예시 (Example), 주장 (Point)의 영어 머리글자다.
주장을 처음과 끝에 두 번 말하는 글쓰기 양식이다. 회의 발언이나 메신저 답글처럼 짧게 의견을 낼 때 쓴다.

## 구성

1. 주장: 하고 싶은 말을 한 문장으로 먼저 쓴다.
2. 이유: 왜 그렇게 생각하는지 쓴다.
3. 예시: 이유를 믿게 할 구체적인 사례나 숫자를 쓴다.
4. 주장: 처음 주장을 다시 한 번 짧게 말한다.

## 예시

[prep-example.md](prep-example.md)에 있다.

## 자주 하는 실수

- 이유와 예시가 같은 말을 되풀이한다. 이유는 왜 그런지를, 예시는 실제로 그랬다는 것을 보여 준다.
- 마지막 주장에서 처음에 없던 새 주장을 꺼낸다.
- 길게 쓴다. 짧게 의견을 내는 양식이라서 길어지면 장점이 사라진다.
