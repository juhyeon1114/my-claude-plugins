# 확장 정의 예시

용어: 호출 제한

## 뼈대

정식 정의
호출 제한은 외부 서비스가 주는 접근 규칙 가운데, 정해진 시간 안에 받아 주는 호출 수의 한도를 정한 규칙이다.

넓히기: 예시
가나몰은 판매자 계정 하나당 1초에 10번, 1분에 300번까지 호출을 받는다.

넓히기: 동작 원리
한도를 넘으면 쇼핑몰은 요청을 처리하지 않고 HTTP 429 응답을 돌려준다. 응답 헤더 `Retry-After`에 얼마나 기다렸다가 다시 부르면 되는지 담겨 온다.

넓히기: 아닌 것 밝히기
호출 제한은 인증 실패와 다르다. 인증 실패는 몇 번을 다시 불러도 거절되지만, 호출 제한은 기다렸다가 부르면 받아 준다.

넓히기: 원인과 결과
주문 수집에서 쇼핑몰을 동시에 많이 부를수록 이 한도에 가까워진다. 실험에서 8곳씩 동시에 부르자 거절이 3건 생겼다. 그래서 주문 수집은 4곳씩만 동시에 부른다.
