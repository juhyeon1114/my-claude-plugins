# 배경

- `~/.claude/output-styles/korean-plain.md`가 있으면 그 글쓰기 규칙과 어투를 따른다.
- AI가 쓴 글은 장황하다. 읽는 사람이 이미 아는 것, 원문을 보면 알 수 있는 것, 묻지 않은 배경까지 담는다.

# 스킬의 동작 방식

## 1단계: 대상 정하기

1. 사용자가 지정한 글 또는 컨텐츠를 줄인다.
2. 지정한 글이 없으면 직전 답변을 줄인다.
3. 대상의 틀은 그대로 둔다. PR 템플릿, 코드블록, 제목 구조처럼 원래 있던 형식은 바꾸지 않는다.

## 2단계: 중요한 것 고르기

읽는 사람이 이 글을 읽고 알아야 하는 것과 해야 하는 일만 남긴다.

남기는 것
- 결론과 핵심 변경.
- 읽는 사람이 해야 하는 일이나 정해야 하는 것.
- 모르면 문제가 생기는 것. 예) 배포할 때 필요한 작업, 기존 동작이 바뀌는 것

지우는 것
- 이유와 배경 설명.
- 원문을 보면 알 수 있는 세부 내용. 예) 클래스 이름 나열, 코드의 동작 순서
- 당연한 내용과 앞에서 한 말을 다시 하는 문장.
- 추측과 조건부 경고. 예) "~일 수 있다", "~라면 ~된다"
- 작성 과정 설명과 끝에 덧붙이는 말.

## 3단계: 다시 쓰기

1. 항목 하나는 한 문장으로 쓴다.
2. 하위 목록은 없앤다. 꼭 필요할 때만 한 단계까지 둔다.
3. 뜻이 겹치는 항목은 하나로 합친다.
4. 원래 없던 내용을 새로 넣지 않는다.
5. 채팅 답변이면 첫 문장에 결론을 쓰고 세 문장 안에서 끝낸다.
6. 결과가 원래 분량의 절반을 넘으면 한 번 더 줄인다.
7. 결과만 보여준다. 무엇을 뺐는지 설명하지 않는다.
