# 출처 고르기

필요한 데이터가 있는 출처를 고르고, 그 출처의 참조 파일에서 API를 찾는다. 스크립트와 참조 파일은 스킬 폴더 `${CLAUDE_SKILL_DIR}` 아래에 있다.

| 필요한 것 | 출처 | 참조 파일 |
|---|---|---|
| 국내와 미국 종목 시세, 캔들, 국내 수급, 토스 섹터, 순위, KOSPI, KOSDAQ, 국고채 금리 | 토스증권 (기본) | `references/toss.md` |
| 해외 지수(S&P 500, 나스닥, 다우, VIX), 원달러 외 환율, 국내 업종 지수, 주봉과 월봉, 시장별 투자자 매매, 프로그램매매 종합, 국내 PER 순위와 추정실적, 투자의견, 배당, 해외 순위와 조건검색, 뉴스 제목 | KIS | `references/kis.md` |
| 미국 종목 스크리닝, 섹터 히트맵, 실적 일정, 내부자 거래 | Finviz (링크만) | `references/finviz.md` |
| 공포탐욕지수 (Fear & Greed Index) | CNN (링크만) | 없음. `https://edition.cnn.com/markets/fear-and-greed` |

- 토스증권과 KIS 둘 다 있는 데이터는 토스증권을 쓴다. 한쪽 자격 증명이 없으면 다른 쪽을 쓰고, 그렇게 했다고 밝힌다.
- 같은 표에 출처가 다른 데이터를 섞으면 열이나 행마다 출처를 표시한다.

# 절대 지침: 거래 금지

- 주문 생성, 정정, 취소, 예약주문, 조건주문 API는 어떤 출처든 사용자가 요청해도 호출하지 않고, 증권사 앱에서 직접 하라고 안내한다.
- 계좌, 잔고, 주문 내역, 매수 가능 금액, 매도 가능 수량을 조회하는 API도 쓰지 않는다.
- 참조 파일의 목차에 있는 API만 `scripts/toss_api.py`, `scripts/kis_api.py` 로 호출한다. `curl`, 직접 짠 코드, KIS Trading MCP로 우회하지 않는다.
- Finviz와 CNN 페이지는 읽지 않고 링크만 만든다.
- 매수, 매도 권유와 목표가 없이, 데이터에서 읽히는 사실과 해석만 쓴다.

# 단계

1. 질문을 출처와 API 조합으로 바꾼다. 어느 출처에도 없는 데이터(국내 재무제표, 국내 공시 원문, 거시 지표)는 그 사실을 먼저 밝힌다.
2. 고른 출처의 참조 파일을 읽는다. 스크립트가 자격 증명이 없다고 하면 참조 파일의 "준비" 절을 안내하고 멈춘다.
3. 심볼을 확정한다. 국내는 6자리 종목코드(`005930`), 미국은 티커(`AAPL`)다. 종목명만 받았으면 토스증권 `/api/v1/stocks/all` 로 찾고, 후보가 여럿이면 사용자에게 고르게 한다.
4. 데이터를 받는다. 서로 의존하지 않는 호출은 한 번에 보내고, 큰 응답은 `--out` 으로 세션의 스크래치 폴더에 저장한다.
5. 계산은 받은 JSON을 Python으로 읽어 하고, 숫자를 어림하지 않는다.
6. 결과를 쓴다. 표나 차트에는 데이터 기준 시각, 출처, 사용한 API 경로를 붙이고, 당일 잠정치가 섞였으면 그렇다고 밝힌다.

# 데이터 이용 정책

- 분석 결과와 받은 데이터는 채팅과 로컬 파일에만 둔다.
- 공유 링크, 슬랙, 노션처럼 다른 사람이 보는 곳에 올려 달라고 하면, 토스증권이 제3자 배포를 금지한다는 점과 KIS 약관은 확인하지 못했다는 점을 알리고 확인을 받는다.

# 사용 예시

## 시장

| 요청 예시 | 쓰는 API | 처리 방법 |
|---|---|---|
| "오늘 시장 어때?" | 토스: 지표 현재가 (`KOSPI`, `KOSDAQ`, `KR_BOND_10Y`), 환율, 주식 랭킹 (`TOP_GAINERS`, `TOP_LOSERS`, `1d`), 섹터 랭킹, 투자자별 순매수, 순매도 상위. KIS: 해외 지수 기간별 시세 (`SPX`, `COMP`, `VIX`) | 전날 미국장, 국내 지수, 금리, 환율, 강하고 약한 섹터, 외국인과 기관이 많이 산 종목 순으로 요약한다 |
| "공탐지수 몇이야?", "시장 분위기 공포야?" | CNN: 공포탐욕지수 링크. KIS: 해외 지수 기간별 시세 (`VIX`) | 공포탐욕지수 값은 CNN 링크에서 확인하라고 안내하고, 함께 볼 지표로 VIX 현재값과 최근 추이를 보여준다 |
| "어젯밤 미국장 어땠어?" | KIS: 해외 지수 기간별 시세 (`.DJI`, `SPX`, `COMP`, `SOX`, `VIX`). Finviz: 섹터 히트맵 링크 | 지수별 등락과 변동성을 표로 쓰고, 섹터 강약은 히트맵 링크로 보여준다 |
| "장 열려 있어?", "다음 주 휴장일 알려줘" | 토스: 국내, 미국 장 운영 정보 | 3영업일치만 오므로 먼 날짜는 `date` 를 바꿔 여러 번 부른다 |
| "외국인이 이번 달 코스피를 얼마나 샀어?" | 토스: 지수 투자자별 매매대금 (`KOSPI`, `1d`), 지표 캔들 (`KOSPI`, `1d`) | 일별 순매수 누적액과 지수 등락을 나란히 표로 보여준다 |
| "프로그램 매매가 시장을 끌었어?" | KIS: 프로그램매매 종합 (일별), 프로그램매매 투자자별 (당일) | 차익, 비차익 순매수와 지수 등락을 날짜별로 맞춰 본다 |
| "최근 1년 S&P 500과 코스피 같이 움직였어?" | KIS: 해외 지수 기간별 시세 (`SPX`, `D`). 토스: 지표 캔들 (`KOSPI`, `1d`, `--pages`) | 시차를 감안해 날짜를 맞추고 일간 수익률 상관계수를 계산한다 |
| "원달러 환율 1년 추이" | KIS: 지수, 환율 기간별 시세 (`X`, `FX@KRW`, `D`) | 기간 고점, 저점, 변화율을 쓴다 |

## 종목

| 요청 예시 | 쓰는 API | 처리 방법 |
|---|---|---|
| "삼성전자 지금 얼마야?" | 토스: 현재가 | 값과 기준 시각을 쓴다 |
| "SK하이닉스 분석해줘" | 토스: 종목 기본 정보, 캔들 (`1d`, `--pages`), 투자자별 매매동향, 공매도, 신용거래, 매수 유의사항. KIS: 현재가 (PER, PBR), 추정실적, 종목 투자의견 | 가격 추세, 밸류에이션, 실적 추정, 수급, 공매도와 신용 부담, 경고 여부 순으로 쓴다 |
| "삼성전자 주봉으로 2년치 보여줘" | KIS: 기간별 시세 (`FID_PERIOD_DIV_CODE=W`) | 100개씩 받으므로 기간을 나눠 받아 합친다 |
| "증권사들이 이 종목 어떻게 봐?" | KIS: 종목 투자의견 | 최근 의견과 목표가 변화를 증권사별로 정리한다. 목표가는 증권사 의견임을 밝힌다 |
| "삼성전자랑 SK하이닉스 비교해줘" | 토스: 현재가, 캔들 (`1d`), 투자자별 매매동향. KIS: 현재가 (PER, PBR) | 같은 기간 수익률, 변동성, 밸류에이션, 수급을 한 표에 둔다 |
| "엔비디아 최근 3개월 흐름" | 토스: 캔들 (`NVDA`, `1d`). KIS: 해외 현재가 상세. Finviz: 종목 상세 링크 | 달러로 계산하고, 재무와 내부자 거래는 Finviz 링크로 안내한다 |
| "오늘 장중에 언제 많이 빠졌어?" | 토스: 캔들 (`1m`, `--pages`) | 고점과 저점 시각, 거래량이 몰린 구간을 찾는다 |
| "이 종목 배당 언제 줘?" | KIS: 배당 일정 (국내), 기간별 권리 (해외) | 기준일과 지급 금액을 표로 보여준다 |

## 섹터와 종목 발굴

| 요청 예시 | 쓰는 API | 처리 방법 |
|---|---|---|
| "요즘 돈이 어느 섹터로 가?" | 토스: 섹터 랭킹 (`1w`, `1mo`, `3mo`). Finviz: 섹터별 성과 링크 | 국내는 기간별 순위 변화를 비교하고, 미국은 Finviz 링크를 함께 준다 |
| "반도체 섹터 대장주 알려줘" | 토스: 섹터 목록, 섹터 구성 주식, 현재가 | `sectorId` 를 찾아 시가총액 상위 종목의 현재가와 등락률을 표로 보여준다 |
| "코스피 업종 지수 중 이번 달 제일 오른 거" | KIS: 업종 구분별 전체 시세, 업종 기간별 시세 | 업종별 월간 수익률을 계산해 순위를 매긴다 |
| "PER 낮은 국내 종목" | KIS: 시장가치 순위 (`FID_RANK_SORT_CLS_CODE=23`) | 회계연도와 분기를 밝히고, 적자 기업이 섞였는지 확인한다 |
| "미국 저평가 성장주 찾아줘" | Finviz: 스크리너 링크 (`fa_pe_u15`, `fa_epsqoq_o25` 등) | 조건을 우리말로 풀어 쓰고 링크를 준다. 원하면 고른 종목을 KIS나 토스로 조회한다 |
| "오늘 미국에서 거래량 터진 종목" | KIS: 해외 거래량 급증 (`EXCD=NAS`, `NYS`) | 거래소별로 받아 합친다 |
| "이번 주 실적 발표하는 미국 종목" | Finviz: 실적 발표 일정 링크, 스크리너 (`earningsdate_thisweek`) | 링크를 주고, 관심 종목을 알려주면 시세를 조회한다 |

## 처리하지 않거나 바꿔서 처리하는 요청

| 요청 예시 | 처리 방법 |
|---|---|
| "삼성전자 10주 사줘", "이 주문 취소해" | 거래 API는 호출하지 않는다고 답하고 증권사 앱에서 직접 하라고 안내한다 |
| "내 보유 종목 분석해줘" | 사용자가 알려준 종목과 수량으로 시세를 조회해 분석한다 |
| "지금 사도 돼?", "목표가 얼마야?" | 판단에 쓸 데이터와 해석만 정리한다 |
| "삼성전자 매출, 영업이익 추이" | 국내 재무제표는 어느 출처에도 없다고 밝히고, KIS 추정실적과 PER, PBR까지만 보여준다 |
| "Finviz 스크리너 결과를 표로 정리해줘" | Finviz 데이터는 받지 않는다고 알리고, 사용자가 종목 목록을 주면 KIS나 토스로 조회한다 |
| "이 분석 슬랙에 올려줘", "공유 링크 만들어줘" | 데이터 이용 정책을 알리고 확인을 받은 뒤에만 진행한다 |
| "실시간으로 계속 지켜봐줘" | 실시간 구독은 하지 않고, 요청할 때마다 현재가를 다시 조회한다 |
